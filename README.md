# Azure DevOps Portfolio

This repository showcases a portfolio of projects and solutions built using Azure DevOps and related technologies. It is designed to demonstrate expertise in CI/CD, infrastructure as code, automation, and modern web development practices.

## Overview

- **Purpose:** Central hub for Azure DevOps projects, automation scripts, infrastructure templates, and web applications.
- **Tech Stack:** Next.js, TypeScript, Azure DevOps, Terraform, Bicep, and more.
- **Audience:** Developers, DevOps engineers, and recruiters interested in DevOps best practices and project samples.

## Features

- End-to-end CI/CD pipelines
- Infrastructure as Code (IaC) with Terraform and Bicep
- Automation scripts and templates
- Modern web applications (Next.js)
- Modular and scalable project structure

## Repository Structure

- `src/` - Source code for web applications
- `public/` - Static assets
- `terraform/` - Infrastructure as Code with Terraform
- `Bicep/` - Infrastructure as Code with Bicep
- `automation-cicd/` - CI/CD automation scripts and templates
- Other folders - Additional portfolio projects and demos

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```
2. **Run the development server:**
   ```bash
   npm run dev
   ```
3. **Open your browser:**
   Visit [http://localhost:3000](http://localhost:3000)
